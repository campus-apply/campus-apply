# resume-facts：工作目录、事实库、口径、偏好

## 不可逆的几条

- **每条事实都要带来源**（【简历 文件名】、【用户口述 日期】）。数字没来源就放"待核对"，不写成已核实的数字——
  后面每一份简历都从这里取材，一个没有来源的数字会被当成事实用下去，面试时对不上。
- **不编事实库里没有的经历和数字**。简历里没写清的（起止月份、数字口径、角色边界）攒成一轮问用户，不自己补。
- **手机号、证件号、住址、密码不进事实库**，也不写进任何文件；用户在对话里给过的证件号同样不记。
- **来源冲突不自行覆盖**：把不同说法和各自出处列给用户，等用户定了再带日期写回。
- **不挪用户已有文件**，需要就复制。
- 不生成简历、不碰浏览器、不上网查用户信息。

## 怎么做

- 初始化与六轮访谈的完整步骤 → `references/steps.md`
- 访谈方法与四套题库（通用口径、求职偏好、个人档案、单次投递）→ `references/interview.md`
- 事实库命名、原则、什么时候用 → `references/steps.md`
- 对用户说话的规矩、停顿怎么安排 → `../campus-apply/references/talking-to-the-user.md`
- 出现"我替用户定几个"这类念头 → `../campus-apply/references/red-flags.md`
- 清单、待决和关联记录更新及交接 → `../campus-apply/references/workflow-state.md`

开工先把 `references/checklist.md` 的清单复制到投递目录，做到哪勾到哪。
