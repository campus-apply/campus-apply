# 控件搞不定、出了事故怎么办

## 控件搞不定
- 同一控件写入无效或找不到：不猜、不重试超过两次。
- 停下来之前截一张浏览器窗口的图放进投递目录 `screens/`，在对话里指出是哪一格、现在什么状态，请用户手动点那一个控件，其余继续由我填。
- 现象记进站点笔记：控件类型、试过的事件序列、失败表现。

## 截图
- 只截网页：`chrome_cdp.py screenshot <路径>` 会把认领的标签页切到前台、只截页面内容；失败就不截并告诉用户。绝不截整屏，整屏会带上终端、聊天窗口和用户正在输入的内容。
- 截图存投递目录 `screens/`，结束时问用户删不删。

## 出了事故
- 先说三句：发生了什么、影响多大、我打算怎么补；然后再动手。
- 补救优先用填写日志里的全量值整页重填。
