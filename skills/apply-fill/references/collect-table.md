# 收集用户信息：一律用表格

凡是要用户提供答案的字段，在对话里列成一张表逐行收集：字段、类型、可选项、默认值、待用户改。

- 下拉和级联先现场探出选项原文列进表里，不能让用户猜。面试站点之类的选项里可能有"线上面试"，外地用户必须知道。
- 默认值取 `campus-apply.json.profile`（性别、出生日期、所在地、期望城市、期望薪资、渠道等），对到本站的选项档位上；档位不一致时填最接近的并注明。
- 用户给了值的字段一律由我填；证件号、密码、验证码永远不经手，用户在对话里给过的任何身份信息都不写进文件和日志。
- 教育经历以及连续的工作经历的起止月份首尾相连（按 `rules.json.style_notes` 的口径），不照抄学校官方的入学和毕业月份留出空档。
- 用户回完把最终值再列一遍确认，等用户说"可以"；用户说"这一页直接填，填完给我看"就跳过确认直接填、回读后再停。
- 这一页缺的材料（成绩单、作品集、证件照）在同一张表里问。
