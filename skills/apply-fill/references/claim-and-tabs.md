# 认领标签页、多标签页与登录

- 先 `list_tabs.sh <公司关键字>` 列给用户看，问用哪一个当工作标签页，`claim_tab.sh <窗口号> <标签号>` 认领，之后一律 `TAB_MARK=<ID>`；跨域跳转会丢标记，`NO_MATCHING_TAB` 时重新列表、重新认领并告诉用户。
- 说明："我只操作认领的标签页，请不要碰它；其他窗口随便用。需要你登录、上传、点提交的时候我会停下来说。"
- Chrome 没开或没有相关标签页：不自己开浏览器，告诉用户打开哪个 URL，等。
- guard 报 `loginRedirect` 或页面要求登录：请用户在这个标签页登录，登录完再继续。
- 表单里填了但没保存的内容，在同一标签页导航到别处大概率丢失。需要同时保留两个页面（申请表和在线简历）时，用 `open_tab.sh <URL>` 自己新开第二个标签页并认领，两个运行 ID 各管一页，告诉用户"我开了第二个标签页给在线简历，申请表那页保持不动"。规矩是只操作我们认领的标签页，不是只能有一个。
