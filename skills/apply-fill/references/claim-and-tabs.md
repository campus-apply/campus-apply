# 认领标签页、多标签页与登录

- 所有浏览器操作都在专用调试浏览器里（`chrome_cdp.py launch` 启动，子命令见总控 skill 的"工具位置"）。它和用户日常的浏览器是两套配置，第一次用要请用户在里面登录招聘站。
- 先 `list <公司关键字>` 列给用户看，问用哪一个当工作标签页，`claim <序号>` 认领，之后每条命令都带 `--mark <ID>`；跨域跳转会丢标记，`NO_MATCHING_TAB` 时重新列表、重新认领并告诉用户。
- 说明："我只操作认领的标签页，请不要碰它；其他窗口随便用。需要你登录、上传、点提交的时候我会停下来说。"
- `list` 报 ERR_NO_CDP（调试浏览器没开）：`launch <URL>` 启动并打开目标页（站点笔记里有就用具体地址），告诉用户"我开了一个专用的浏览器窗口，登录请在这个窗口里做"，等用户说好再继续；不碰用户日常的浏览器。
- guard 报 `loginRedirect` 或页面要求登录（包括弹出登录框）：请用户在这个标签页登录。弹窗式登录完成后页面上的表单往往还是登录前取到的空数据，先确认没有未保存的内容，刷新一次再探测。
- 表单里填了但没保存的内容，在同一标签页导航到别处大概率丢失。需要同时保留两个页面（申请表和在线简历）时，用 `open <URL>` 自己新开第二个标签页并认领，两个运行 ID 各管一页，告诉用户"我开了第二个标签页给在线简历，申请表那页保持不动"。规矩是只操作我们认领的标签页，不是只能有一个。
