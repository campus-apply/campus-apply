# 自述怎么写（自我描述、自我评价、个人陈述、求职信）

## 一段只说一件事，结构是事实加分析
每段三部分：
1. 总起句：说这段讲什么，带"我"，像人在说话（"课外活动方面，我把时间主要给了音乐和运动""最近，我重读了《某某》这本书"）。
2. 事实：这件事本身，有时间、对象、动作、结果，数字来自事实库。同一类的事放同一段（所有课外活动一段、所有社会工作一段），不要打散到各处。
3. 分析：这些事对我意味着什么、改变了我什么、和这个岗位有什么关系。分析要具体到做法或判断，不是"让我收获很多""为未来打下基础"这种放哪都行的话。

读书段的写法："最近，我重读了《X》这本书。这本书讲的是……的故事。这不是我第一次读，但……之后再读，感受不一样了：（具体的感受，落到自己怎么做事）"。

课外活动段的写法：总起句点明主要投入了哪几样，然后每样一两句（学了多久、到什么程度、做过什么），最后一句说这些事共同练了什么。

党员身份：用户是党员的（看 `campus-apply.json.profile.politics`），自述可以写，一般放第一段开头附近，一句话带年份即可。

## 固定流程（四步，一步不能省）
0. 先问用户有没有现成的材料：以前写过的个人陈述、求职信、自我评价、年终总结，或者别人写得好的范文。有就先读，从里面抽事实、抽用户自己的说法和写法，再写；没有就按本文的写法写。
1. 结构表给用户：分几段、每段写什么、大约多少字、哪些地方要用户提供素材或做选择；目标字数第一次写时问用户一次，记进 `rules.json` 的 `self_statement_length`，以后不再问（站点有上限按上限）。
2. 初稿。观点段（对公司的看法、为什么投这个岗）先请用户口述一两句，哪怕很粗，只做扩写和接事实；用户没话说就给两三个候选，**候选要写成成段的话让用户看，不能只给标签**，用户挑了还要改一句成自己的话再用。
3. 按 `humanizer.md` 逐条过一遍改稿，写出改动总结和评分表；35 分以下重写。
4. 全文加改动总结加评分表一起给用户，用户认了才写进页面。

## 句子
- 句子完整，主谓宾齐全。碎片罗列（一句话逗号连四五个名词）读起来像清单，改成有主语有动作的句子，并且说明它们为什么放在一起。
- 动作加结果："先后组织多场活动，培养了团结他人的能力"这种写法可以用；只有动作没有结果的句子要补结果或删。
- 可以有一句短主题句或引导句，比如"我想谈谈我想做什么样的工作""先说一件我自己折腾出来的事"，这种带"我"的引导句读起来是人在说话；不许的是预告式起手（"最有意思的一件事发生在…"）和用冒号把下文引出来的宣告句（"我对X的看法集中在一点："）。
- 引号只给书名（书名号）、项目名、机构名和别人的原话；自己造的短语不加引号。
- 语气书面但不公文：完整的句子、第一人称，可以有"我觉得""其实"，不用"致力于""开展""切实"这类公文词。
- 一段里句子长短要有变化；段末不要总是同一种收法。

## 篇幅与结构
- 一篇自述五段上下，每段 250–400 字，总长按用户给的目标字数（问一次记进 rules.json）；要加长就加事实和细节，不加形容词。
- 段落顺序按岗位要求排：岗位点名要的证明（如"折腾过的事""对公司的看法""最近读的书"）各自成段，顺序照岗位描述的顺序。
- 自述不重复简历：能力证据用一件事讲透，其余留给简历；篇幅给简历里没有的东西——动机、判断、习惯、性格证据。
- 语气诚恳、正式，"我"贯穿全文，可以用"第一、第二"。

## 常见段落的写法
- 定位段：身份一句 + 一件实习/项目里的事讲完整 + 结论"我想做的是这类工作，因为…"。
- 做过的事段：起因（具体的不方便）→ 做了什么 → 现在怎么用/结果 → 更早一件同类事一句 → 两件事的共同点。
- 看法段：一个判断 + 为什么（自己的观察或经历）+ 这个判断意味着这个岗位要做什么 + 和自己经历的连接。
- 习惯段（读书、运动）：书讲了什么（两句）→ 它改了我哪个想法 → 这个想法在我做事时怎么体现 → 运动作为另一种长期坚持的事 → 共同点。
- 社会工作段：角色 + 规模 + 最难的一件事怎么解决 + 结果；结尾说这些经历练的是哪种能力。

## 自查
写完逐段问：总起句有没有；事实有没有数字和对象；分析是不是只对这段成立；有没有碎句；有没有能引用的金句；段末是不是又用了同一种收法。再按 `humanizer.md` 逐条过一遍。
