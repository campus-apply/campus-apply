# 执行清单怎么用

开工先把本 skill 的清单复制成 `applications/<公司>/<skill>-执行清单_<日期>.md`（还没有公司时放 `applications/_工作区/`），做到哪勾到哪。

- 停顿行写"等用户回复：时间"；完成一步就回头把那一行改成 `[x]`，不在末尾另起已勾的行，跳步会留空格。
- 一个 skill 末尾"等用户选下一步"的那行，在用户给出选择、下一个 skill 开始时回头勾掉并记时间，别让它一直空着。
- 续作时读当前清单，不重建一份绕过未完成项；更新规则见 `workflow-state.md`。

各 skill 的清单正文：

- resume-facts → `../../resume-facts/references/checklist.md`
- job-screen → `../../job-screen/references/checklist.md`
- resume-tailor → `../../resume-tailor/references/checklist.md`
- apply-fill → `../../apply-fill/references/checklist.md`
