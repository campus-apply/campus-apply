# 红旗：出现这些念头就停下来照清单走

- "这个站简单，不用建执行清单了。"
- "跟用户说一下这是技能要求的，他就明白为什么要停了。"
- "先把志愿页和基本信息填上，简历一会儿再改。"
- "附件等填完字段再传，反正都要提交。"
- "这页不需要简历文本，可以先走。"
- "先把表填上，回读和报告一会儿再补。"
- "md 已经写了，xlsx 下次再出。"
- "用户说先用旧的自评，那就直接贴。"
- "题太多了，用户肯定嫌烦，我替他定几个。"
- "这个字段我凭常识填一个，用户应该会同意。"
- "页面看不见人数，隐藏节点里有，就用那个。"
- "接口返回得挺全，抽样比对就免了。"
- "两次没写进去，再试几次总能行。"
- "缺个包，先装上再说，用户不会在意。"
- "显示值对了，肯定存上了，让用户明天再看。"

念头出现时，回到执行清单看当前行是什么。
